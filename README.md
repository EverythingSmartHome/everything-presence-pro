# Everything Presence Pro

The Everything Presence Pro is a presence sensor for the smart home. It uses mmWave to detect presence, with Wi-Fi or Ethernet (PoE) versions, and integrates directly with [Home Assistant](https://www.home-assistant.io/) through [ESPHome](https://esphome.io/).

If you'd like to buy the Everything Presence Pro, that is located [here](https://shop.everythingsmart.io/products/everything-presence-pro).

The official user guide for the Everything Presence Pro is located [here](https://docs.everythingsmart.io/docs/products/everything-presence-pro)!

This repository contains the ESPHome configuration and firmware builds for the Everything Presence Pro.
